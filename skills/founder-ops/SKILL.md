# Founder Operations

## Investor Update Template
```markdown
Subject: [Company] — [Month] Update

**TL;DR**: [One sentence summary of the month]

### Metrics
| Metric | Last Month | This Month | Change |
|--------|-----------|------------|--------|
| Users  |           |            |        |
| MRR    |           |            |        |
| Burn   |           |            |        |

### Wins
- [Top 3 accomplishments]

### Challenges
- [What's hard right now]

### Asks
- [Specific things investors can help with]

### Next Month
- [Top 3 priorities]
```

## Outreach Email Framework
For cold outreach (investors, partners, customers):
1. **Hook** — One sentence that shows you did your homework
2. **Problem** — What you solve (their perspective, not yours)
3. **Proof** — Traction, metrics, or social proof
4. **Ask** — One specific, low-friction CTA
5. **Close** — Keep it under 150 words total

## Content Calendar (MWI Brand)
- **Monday**: Motivation / founder journey
- **Tuesday**: Technical tutorial or build log
- **Wednesday**: Industry insight or hot take
- **Thursday**: Community engagement / replies
- **Friday**: Free game — give away something valuable

## GTM Checklist for New Features
- [ ] Who is this for? (specific persona)
- [ ] What's the one-line value prop?
- [ ] Where do they hang out? (channel)
- [ ] What's the first-touch message?
- [ ] What's the success metric? (not vanity)

## Weekly Founder Review
Every Friday, answer:
1. What did I ship this week?
2. What did I learn?
3. What's blocking me?
4. What's my #1 priority next week?
5. Am I working on the right thing?
